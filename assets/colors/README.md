# Color Configuration

This file contains the color palette configuration for easy customization.

## Current Palette

- **Primary**: #1a1a1a (Dark text)
- **Accent**: #6366f1 (Indigo)
- **Accent Light**: #a5b4fc (Light indigo)
- **Background**: #fafafa (Light gray)
- **Surface**: #ffffff (White)
- **Text Muted**: #6b7280 (Gray)

## How to Update Colors

1. Edit the CSS custom properties in `app/globals.css`
2. Update the `@theme inline` section
3. Colors will automatically apply throughout the site

## Color Usage

- **Primary**: Main text and headings
- **Accent**: Buttons, links, and highlights
- **Background**: Page background
- **Surface**: Card backgrounds
- **Text Muted**: Secondary text

## Accessibility

All color combinations meet WCAG AA contrast requirements (4.5:1 for normal text, 3:1 for large text).
